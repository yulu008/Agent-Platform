⭐ 星命推演

填入你的生辰，星光会替你选定星座、星阶与命定招式。推演结果会写进本局存档，开场白与 GM 都能读到。

🌟 你的命定身份

小宇宙：-

下面三项已按星命预填，你可以改成自己想要的样子——它们会写进本局的角色卡。

📖 资料来源

选择本局资料库（设定集 + 通用世界书）的初始来源。开局会复制一份为本存档专属副本，之后在游戏内弹窗就地编辑，与世界模板及其他存档互不影响。

你的作品

点击作品进入编辑；「▶」试玩选角开局（存档进「📜 存档」）；或点空白卡新建一个世界

世界观设定

可覆盖变量：--hud-gold / --hero-accent / --npc-accent / --panel-bg / --hud-mind-accent；值为 hex 或 rgb[a] 颜色。仅作用于本世界的 GM 气泡组件。
每块 {title, field, accent?}：title 块标题（≤20 字符）；field 模型输出字段名（字母开头，仅字母数字下划线，≤64，如 objectives）；accent 强调色变量（--hud-gold / --hero-accent / --npc-accent / --panel-bg / --hud-mind-accent，缺省 --hud-gold）。最多 5 块；模型每轮经 state_delta 输出 field 对应数据（数组建议每项 {text, done}），块随回合更新。
无封面
支持 png/jpeg/webp/gif，≤ 4MB；保存世界后可上传

📖 设定集（世界书）

本世界的设定集词条（世界模板种子）。此处只读，真源在 preset-adventure.md，重新物化时全量重写；每局开局的专属副本编辑在游戏内「📖 资料库」弹窗。

触发器

让 NPC 在条件满足时主动行动（硬条件＋软条件＋概率＋冷却），命中时向 GM 下达行为指令——管“谁在何时做什么”。静态背景用「世界书」，长线设定用「设定集」。需先在「世界观」tab 选定或新建世界。

世界书

关键词命中时，仅当轮把条目正文注入 GM 叙事，滑出即忘——适合场景背景与氛围补充。需要长线记住的设定（人物、组织、概念）请用「📖 设定集」。需先在「世界观」tab 选定或新建世界。

故事图

分支叙事骨架（幕→节点→边→变体）：节点只存拍子不写正文，正文开局后由 GM 物化。「保存图」即时校验语法与词汇表；「整稿通过」执行全图校验链并确定性修复。需先在「世界观」tab 选定或新建世界。

📖 选择资料来源

开局会复制一份为本存档专属副本，之后在游戏内弹窗就地编辑，与世界模板及其他存档互不影响。

可选：挂一张已整稿的故事图开局——分支剧情按图推进、选择确定性结算；不选则保持自由沙帛。

🧭 已走分叉点

回退到任意已走分叉点：状态按「初始态 + 保留已走边」确定性重放，被回退的选择不再生效；对话记录保留不删。

🚀 发布到共享库

发布当前世界模板条目（存档副本不可选）的时点快照，全平台登录用户可见可导入。此后源模板增删改不影响包，直到你再次发布覆盖；同世界重复发布会覆盖自己的旧包。

🌐 共享世界书库

全平台登录用户可见的公开内容库。导入后条目成为当前世界的独立模板行，此后与共享包互不影响（快照哲学）。
