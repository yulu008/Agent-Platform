# 预设冒险世界源文

## 名称
圣斗士·天下争圣

## 时代
日本战国时代·弘治二年（西历1556年），稻生合战未起，织田信长与其弟信胜陈兵相向；室町幕府名存实亡，下克上之风席卷列国

## 氛围
下克上的乱世与星座的宿命交织，人命如草芥，而星光偏在最黑处亮起；圣衣随改朝换代不断易主，每一次燃烧都要付出代价

## 规则
- 一切战斗的能量核心是「小宇宙」：燃烧程度决定强度上限，圣衣随小宇宙共鸣而进化；
- 圣衣破损后须由各地锻造町（必须是能生产火枪的锻造町才能修圣衣）、寺庙、神社内的圣衣匠师修复
- 玩家不可越阶碾压：以下位圣衣挑战上位者，只能靠地形、计谋、同伴的牺牲或第七感的瞬间觉醒换取短暂上风，不存在稳定获胜的正面硬拼
- 各体系圣衣都认主而不认家名：大名可以夺来圣衣箱，却强求不到圣衣的承认，未被选中者穿戴时圣衣沉重如铁——这正是乱世中圣衣不断易主、下克上频仍的根源
- 登场角色一律给出汉字名与所属家门或势力（各大名家 / 足利幕府 / 黄泉冥界 / 水军），全程以汉字指称，禁止罗马音与纯英文名；关键 NPC 的状态写入 npc_states
- 冥星武将录中的 14 位战国武将是世界里的 NPC：各自命定持有一件冥衣，玩家不会变成他们；若玩家推演出的主命星撞上某武将的命定星，则这一局里该武将不再持有那件冥衣——星归玩家，他的命运轨迹也随之改变

## 世界描述
**这里没有雅典娜、冥王哈迪斯、海皇波塞冬和奥丁**。圣衣、冥衣、鳞衣、神斗衣经遣唐使从大陆渡海而来、散落列国的神器，认主而不认家名；1556年的日本尚无统一之主，圣衣随合战、联姻与背叛在各大名之间流转——所谓「圣战」，已不再是祭祀某位神祇的仪典，而就是这天下逐鹿本身。

黄金十二宫圣衣分镇强藩：白羊在室町足利家（列国圣衣多赖其匠师修复），金牛在矶野家矶野员昌之手，双子归武田家，巨蟹归吉川家，狮子归关东北条家，处女归越后长尾家，天蝎归阿波三好家，射手归骏河今川家（今川主号称「东海道第一弓取」，此衣命定于桶狭间之后转入明智光秀之手），摩羯为历代「剑圣」所承、此时正握在冢原卜传掌中，水瓶归陆奥伊达家；天秤一分为二，丰后大友与萨摩岛津各执其半。

青铜与隐藏圣衣多在下克上的新锐之家：织田家藏仙女座圣衣，当主信长年二十有二，新取清洲，其弟信胜拥兵末盛与之分庭；松平家得天马座圣衣；出云尼子家承凤凰座（隐藏圣衣，浴火重生）；陆奥伊达家于水瓶座黄金圣衣之外另握天鹅座青铜圣衣，北国苦寒，故伊达兼掌冰之黄金与冰之天鹅，寒意冠绝列国。

圣斗士之外另有三股力量。足利幕府的「三管四职」七家——斯波、畠山、细川、一色、赤松、京极、山名——各应北斗七星之一，是为「神斗士」，身披神斗衣，人数最少而出手即杀招，名义上拱卫将军、实则各怀异心。扼守濑户内海与诸国水路的村上水军等水军将领皆持鳞衣，为「海斗士」或其候补，谁掌海道谁便断得他家粮道。而在黄泉之侧，一百零八件冥衣沉睡未醒，以魔星分为天罡三十六与地煞七十二，随乱世死亡的累积而逐件苏醒、陆续现世；冥衣一旦认主，其「冥斗士」便能复活死者、亦能封印他人的小宇宙。无人见过冥界之主，正如无人真正见过深居京中的将军——这两桩讳莫如深，本身就透着不祥。

圣衣是有生命的，沉睡在对应的圣衣箱中，唯有被星座选中者能唤醒它；穿戴者的意志若崩溃，圣衣便沉重如铁。圣衣损坏到某个程度会自行碎裂，那碎裂声被老兵称为「星的哀鸣」。

叙事的基调是：少年人在下克上的乱世里背负不属于自己的宿命，用会流血的身体去出人投地，同伴的死亡、感官的丧失都是常见代价。请让每一次爆发都有前置积累，让每一方——争圣衣的大名、拱卫幕府的神斗士、扼守海道的海斗士、自黄泉归来的冥斗士——都有自己的正当性，让玩家的选择真正改变这乱世的格局。
